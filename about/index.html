Attention-Driven Depth Fusion: Leveraging Focus and Single-Image Priors with Self-Cross Attention

Rui Yan, Zaitian Gongye

We propose an end-to-end model that fuses a single RGB image and its defocus map using attention mechanisms to estimate depth. Instead of handcrafted fusion, it uses self- and cross-attention for uncertainty-aware refinement.
